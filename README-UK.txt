PRO2052 1.0.0 — Windows та Intel macOS

WINDOWS
Встановіть 64-бітний Python 3.13 або 3.12 з Python Launcher.
Запустіть build-windows.cmd. Він створить EXE, ZIP та MSI в dist/windows.
EXE потребує папки _internal поруч; для встановлення використовуйте MSI.
Дані зберігаються в %LOCALAPPDATA%\PRO2052 і залишаються після видалення.
Збірки не підписані сертифікатом видавця.

INTEL MAC
PRO2052 1.0.0 — комплект для Intel Mac, цільова система macOS 15.8.3

Це адаптований вихідний код і засоби збирання, а не готовий .app.
Збирання та остаточна перевірка виконуються на вашому Intel Mac.

1. Встановіть Python 3.13 для macOS з офіційного сайту:
   https://www.python.org/downloads/macos/
   Потрібен інсталятор Python 3.13 із Tkinter. Підтримується також Python 3.12.
2. Розпакуйте цей ZIP у звичайну папку на Mac.
3. Відкрийте Термінал, введіть bash і пробіл, перетягніть build.command у вікно та натисніть Enter.
   Ця команда встановлює залежності лише в локальне середовище .venv цього комплекту.
4. Дочекайтеся завершення. Папка dist міститиме PRO2052.app і PRO2052-1.0.0-Intel.dmg.
5. Відкрийте DMG і перетягніть PRO2052 у Applications.

ПІДКЛЮЧЕННЯ
Підключіть USB–RS-232 адаптер, натисніть «Оновити порти».
Виберіть порт на зразок /dev/cu.usbserial-… або /dev/cu.usbmodem…
Якщо порту немає, перевірте підтримку macOS у виробника конкретного адаптера.
Установіть швидкість, що відповідає сканеру, та ввімкніть REMOTE.
Спочатку перевірте читання одного каналу. Не починайте з масового запису.

ДАНІ
~/Library/Application Support/PRO2052
Кнопка «Папка даних» відкриває цю папку у Finder.
Кнопка «Імпортувати дані…» переносить копії зі старої папки data, не замінюючи наявні файли.
Після перенесення даних Windows виберіть порт Mac заново та збережіть підключення.
Імпорт частот CSV: «Програмування каналів» → прочитати всі канали → «Редактор / CSV / відновлення».

ПІДПИС
Локальна збірка має технічний ad-hoc підпис PyInstaller, але не підтвердженого видавця Apple.
Для публічного поширення потрібні Apple Developer ID Application і нотаризація Apple.
Сертифікат підписування Windows не замінює Developer ID.
Цей комплект не вимикає захист macOS і не виконує нотаризацію.

ПЕРЕВІРКИ
Сценарій перевіряє архітектуру Intel, цілісність локального підпису та образу DMG,
а також виконує тест запуску програми без команд сканеру.
Звіт: build/self-test.json. При помилці надішліть текст із Термінала.
Фактичне збирання на macOS і робота з фізичним сканером ще не перевірені автором цього комплекту.
